# Rocket Tec Wafle Landing Page

Página web estática lista para desplegar en **GitHub Pages**.

## Archivos incluidos
- `index.html`: Página principal responsiva con el logotipo de la marca de cohete Wafle, secciones informativas del Tec de Monterrey Campus Sinaloa y lanzamiento 2026.
- `.nojekyll`: Archivo necesario para asegurar que GitHub Pages sirva correctamente la landing page sin procesadores de Markdown.

## Instrucciones de Despliegue en GitHub Pages (Paso a Paso)

1. **Descomprimir**: Extrae los archivos de este archivo `.zip`.
2. **Subir a GitHub**:
   - Entra a tu repositorio en GitHub (o crea uno nuevo público).
   - Haz clic en **Add file** > **Upload files**.
   - Arrastra y suelta los archivos `index.html`, `.nojekyll` y `README.md`.
   - Haz clic en **Commit changes**.
3. **Activar GitHub Pages**:
   - Ve a la pestaña **Settings** (Configuración) de tu repositorio.
   - En el menú lateral izquierdo, haz clic en **Pages**.
   - En **Build and deployment > Source**, selecciona **Deploy from a branch**.
   - En **Branch**, selecciona `main` (o `master`), deja `/ (root)` y haz clic en **Save**.
4. **Listo**: En unos segundos tu página estará en vivo en `https://tu-usuario.github.io/tu-repositorio/`.
